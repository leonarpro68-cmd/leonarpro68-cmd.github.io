Robotics projects

2026 · ongoing

Bipedo — 12-DOF bipedal robot

Designed and 3D-printed a 1.57 kg, 0.46 m biped (12 STS3215 servos, Raspberry Pi 5, IMU). CAD-to-MJCF generator; RL walking policy in mjlab (87–91 % forward speed tracking, no falls) run sim-to-sim in Gazebo through a C++ plugin; real-leg tests with servo telemetry.

2026 · ongoing

Pentabot — 15-DOF five-legged robot (team project)

Encoder-free PPO locomotion policy for servos without position feedback. Across 256 randomized robots: 83–89 % speed tracking and 0 % falls vs 54–86 % and 6–10 % with encoders; ≈84k-parameter network for an ESP32.

2026 · ongoing

ArmCar — mobile manipulator with a voice AI agent

Distributed ROS 2 Jazzy system (PC + Raspberry Pi 5, 8 packages): IK teleoperation, differential drive with watchdog, and a Claude agent with local speech (Whisper, Piper) that moves the real SO-101 arm; RViz digital twin with calibrated limits.

2026 · ongoing

Swarmbots — Summit XL swarm simulation

PUCP collaborative robotics research, simulation lead. Migration to ROS 2 Jazzy / Gazebo Harmonic, 6 worlds, color-sorting pick-and-place cycle (3 robots, 6/6 pieces, 0 collisions), rosbag2 → HDF5 pipeline for ACT.
